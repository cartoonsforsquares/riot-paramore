# Riot

A free, hand-drawn fan font in three styles (Marker, Scrawl and Scribble), inspired by the lettering on Paramore's *Riot!*. Designed by a fan for other fans.

Live site: https://cartoonsforsquares.github.io/riot-paramore/

- Test the font, download a PNG of your words, and make a 6×4 post card from your own photos.
- Free for personal use. This is a fan-made project and isn't affiliated with the band or their label.
- Post card handwriting uses [Beth Ellen](https://fonts.google.com/specimen/Beth+Ellen) (SIL Open Font License, see `fonts/BethEllen-OFL.txt`).
